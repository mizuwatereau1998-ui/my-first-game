# 単語の意味と、待つと震えるヒント

> 配置・補充・ヒントは、その後の [5〜6文字優先の調整](LONG-WORDS.md) を適用します。以下の旧方針に関する記述は同資料で更新されています。

## 正解時の意味表示

盤面上の発見演出とRECENT WORDSに正解した英単語と日本語の意味を表示します。手動の正解にも、自動連鎖にも対応します。連鎖が進むと表示も更新されます。

「見つけたことば」のボタンを押すと、その単語の意味を見返せます。得点や盤面は変わりません。現在の履歴は今回のプレイの直近3種類で、同じ語の発見回数をまとめて表示します。永続コレクションではありません。リトライで履歴をリセットします。

日本語訳は現在381語分。CAT「猫」、DOG「犬」、AFFORD「〜する余裕がある」、EFFORT「努力」などを表示します。正解語彙3,000語の全語の日本語訳を整備したものではありません。訳のない登録単語も通常どおり正解にし、「日本語の意味は準備中です」と表示します。

訳のデータは `words.js` の `WordPopDictionary` にあります。ゲーム中は辞書APIへの問い合わせを行いません。発音機能・保存付きコレクションは未実装です。

## 自動ヒント

- 操作せず15秒待つと、現在の盤面で実際につくれる単語を1つ選びます。
- 初回チュートリアル中はCAT、それ以降は身近な3〜4文字の単語を優先し、なければ3,000語から探索します。
- 答えのブロックに1、2、3…の番号と黄色の強調を付け、約0.1秒ずつずらして軽く左右に震わせます。待ち続ける間は約4秒ごとに繰り返します。
- 得点・単語・盤面は変えず、プレイヤー自身がなぞります。減点・回数制限はありません。
- なぞり始めると案内を止めます。選択中、消去・落下・連鎖中、遊び方の表示中、タブを隠している間は表示しません。
- 正解・不正解・取り消し・リトライ・遊び方を閉じると待ち時間を数え直します。落下があった場合は、その後の盤面から答えを選び直します。
- OSやブラウザの「動きを減らす」設定では震えず、色と番号だけで案内します。

待ち時間は `game.js` の `IDLE_HINT_MS = 15000` を変更して調整できます。この自動経路ヒントは、仕様書にある「意味→頭文字→経路」のボタン式3段階ヒントの全実装ではありません。

## 確認方法

1. `index.html` を開いて操作せず15秒待ち、答えのブロックが震えることを確認します。
2. 光った文字を番号順になぞると、正解し、日本語の意味がメモに表示されます。
3. 別の単語を作り、履歴から前の単語を押して意味を見返します。
4. 再び15秒待ち、今の盤面にある単語を案内することを確認します。

開発用の自動確認はHTTPサーバーを起動して以下を実行します。追加のゲーム実行用依存関係はありません。

```sh
node --test tests/*.test.cjs
node tests/browser.cjs
node tests/learning-browser.cjs
```

`learning-browser.cjs` はPlaywrightの仮想時計を使い、実時間の15秒を何度も待たずにタイマーの境界と抑止・再開を検証します。意味の表示、履歴、訳未整備の登録語、現在の盤面との一致、動きを減らす設定も確認します。

## 盤面に出る発見演出

消去・落下・着地が終わってから、盤面中央に英単語・日本語訳・加点が順に登場します。英単語が柔らかく弾み、0.2秒遅れて訳、0.35秒遅れて得点が現れ、全体は約1秒で消えます。連鎖では次の消去が始まる前に表示を消します。詳細は [ANIMATION.md](ANIMATION.md) を参照してください。

訳未整備の語は「意味は準備中」です。演出は盤面の操作を遮らず、次の文字を選択するとすぐに消えます。リトライ時には演出とタイマーもリセットします。OSの「動きを減らす」設定では弾む動きを省き、同じ時間だけ静止表示します。

盤面の一時表示が消えた後もRECENT WORDSの履歴で意味を確認できます。演出の確認は、HTTPサーバーを起動して `node tests/effects-browser.cjs` を実行します。消去タイミング、単語と訳、連鎖での切り替え、自動終了、操作の通過、スマートフォン幅で6文字が収まること、動きを減らす設定を検証します。
