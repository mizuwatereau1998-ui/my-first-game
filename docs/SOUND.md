# BGM・効果音（Web Audio試作）

音声ファイルや外部サービスを使わず、`audio.js` で生成します。単語判定・得点・連鎖候補には触れません。

## 設定と再生開始

- 最新のユーザー指定により、初回は **BGM・効果音とも ON**。
- 遊び方1ページ目に「※音が鳴ります。BGM・効果音は『音の設定』でOFFにできます。」を表示。
- 読み込み直後はAudioContextを作らず、最初のポインター・キー操作または設定操作から生成・再生します。保存済みのON設定でも操作前に勝手に再生しません。
- 上部の「♪ 音の設定」で個別にON/OFF。遊び方1ページ目とRESULTからも設定を開けます。
- `localStorage` の `word-pop-sound-v1` にBGM/SFXの真偽値だけを保存。利用できない場合は今回のプレイ中だけ適用します。ユーザーがOFFにした設定を次回の既定ONで上書きしません。
- 設定画面中はゲーム時間と入力を一時停止します。遊び方や連鎖の停止と重なっても、すべて解除されるまで再開しません。

## 鳴るタイミング

| イベント | 音 |
| --- | --- |
| 文字が新しく選択される／1文字戻す | 短く柔らかい高音の「プチッ」。同じマス上の移動では連発しない |
| ボタンを押す | 軽い「ポコッ」 |
| 手動の正解で消去開始 | 明るい3音の「ポン＋キラリン」 |
| 2連鎖の消去開始 | 少し高い4音の上昇音 |
| 3連鎖以上の消去開始 | 5音の短いファンファーレ |
| 文字の落下・補充が着地完了 | 低めで小さな2音の「コトコト」。ブロックごとではなく1回の着地につき1組 |

BGMは柔らかい正弦波のメロディーと小さな三角波の低音による約8.6秒のループ。BGMの音量を効果音より控えめにしています。選択55ms・着地120ms等の連続発音制限と、最大28ボイスの上限を設けています。

BGM用のスケジューラーは1つだけ。ON/OFF、画面非表示、pagehideで既存の音とスケジューラーを止めます。再表示時は以前ユーザー操作で有効になっていた場合だけ再開を試みます。未対応API・再生拒否・音声読み込み失敗でも、ゲームは継続できます。再生できない環境は設定画面に案内します。

## 後からファイルBGMへ交換

ファイルをプロジェクト内へ追加し、初期化後に次のAPIを呼べます。設定とユーザー操作による再生許可は同じ仕組みを使います。

```js
WordPopAudio.setBgmSource('assets/audio/bgm.ogg');
// 生成BGMへ戻す
WordPopAudio.setBgmSource(null);
```

ファイルもループし、差し替え時に古い再生を停止します。効果音の音色・音程・長さは `audio.js` の `sfx()` と `tone()` に分離しています。現段階では外部音声の音質・実機の音量感までは検証していません。
