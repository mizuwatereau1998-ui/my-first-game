# ぷにぷに・キラキラの演出

現在のブロック・パステル背景・金色フレーム・画面構成を保ち、動きだけを調整しています。配置・補充は [LONG-WORDS.md](LONG-WORDS.md)、ポップンの画像と復帰仕様は [CHARACTER.md](CHARACTER.md)、UI構成は [UI-REFINEMENT.md](UI-REFINEMENT.md) を引き続き適用します。

## 選択から落下まで

- 選択したマスは約0.25秒で柔らかく膨らみ、約1.055倍の状態で明るく表示。取り消すと元に戻ります。マウス・タッチ・キーボードで同じ反応を使います。
- 正解時は選択順に12msずつずらし、一瞬膨らんで縮みながら消えます。最長6文字でも240ms以内に完了します。
- 星・光の粒は弾けるタイミングに合わせて散ります。中央の英単語・訳・加点表示は落下・着地が完了してから登場し、約1秒で消えます。次の選択でも即座に消えます。詳しい表示順は下記「ポップアップ・リワード」を参照してください。
- 落下は380ms。実際のブロックの高さと行間隔を測り、既存文字は元のマスから、新しい文字は盤面の上から移動します。加速して着地し、少しつぶれて小さく弾みます。落下する既存ブロックは元の色も引き継ぎます。
- 通常の1語は消去240ms＋落下380msで、従来の入力待ち時間を増やしません。消去・落下・連鎖中の入力ロックは維持します。粒子が消え切るのを待って操作を止めることはありません。

## 連鎖とポップン

2連鎖では粒子が増え、連鎖表示が弾みます。3連鎖では金色の輪が盤面内に広がり、4連鎖では左右の星が短くきらめきます。画面全体の点滅や揺れは使いません。

各語の落下後にリワードを1秒表示してから、次の連鎖へ進みます。連鎖候補の予告は300ms。候補を強調してから、実際の消去開始に合わせてポップンの表情とジャンプを切り替えます。待機時の動き・PNG・顔の位置・サイズ・表示範囲・終了後650msの復帰・古い復帰タイマーの取り消しは維持しています。

連鎖判定・候補優先順位・倍率・最大4連鎖・長語保護は変更していません。`engine.js`・辞書・画像は変更していません。

## 実装と負荷

`motion.js` は見た目専用の独立したレイヤーを必要時だけ作ります。粒子数は1ブロックにつき通常3、2連鎖5、3連鎖7、4連鎖9。6文字でも装飾は最大67要素で、1000ms後にレイヤーごと削除します。次の消去・リトライ時にも古いレイヤーと削除タイマーを解除します。

装飾は盤面の内側に収め、ポップンの上へ飛び出さず、`pointer-events: none` と `aria-hidden` を指定しています。ゲームの乱数を演出では使わず、抽選結果へ影響させません。アニメーションは主にtransformとopacityを使い、常時のフレーム更新処理は追加していません。外部ライブラリ・通信・音は追加していません。

`prefers-reduced-motion: reduce` では粒子を生成せず、膨張・移動・バウンドを停止。選択の輪郭、消去時の薄い表示、単語・訳・加点、連鎖表示と表情切り替えは残し、同じルールで遊べます。

## 検証

HTTPサーバーを起動し、既存のNodeテストと全ブラウザテストに加えて次を実行します。

```sh
node tests/animation-browser.cjs
```

追加テストではPC・390px・320px幅の落下開始位置、補充の開始位置、文字と色の引き継ぎ、加速、着地の弾み、消去順、演出中の入力抑止、連続消去、粒子の削除、動きを減らす設定を検証します。連鎖の表示とキャラクターのタイミング検証では候補だけを固定し、2〜4連鎖の段階と5連鎖へ進まないことを確認します。実際の連鎖ルールは既存のNode・ブラウザテストで検証します。

ヒントの既存テストは、非同期のdialog closeイベントを受けてから仮想時計を進めるよう同期を補強しました。15秒の境界・ダイアログ表示中の抑止の検証は維持しています。発見演出の既存テストでは、検証対象の2連鎖より後にランダムな追加連鎖が起きて最終履歴が変わらないよう、テスト用の補充文字を固定しました。ゲーム本体の抽選は変更していません。

スマートフォン実機・Safariの動作と実機での滑らかさは未確認です。クラウドの制限によるfile://検証のスキップと、HTTPでの検証は区別します。


## ポップアップ・リワード

消去240ms→落下380msを見せ、着地した時点を0msとして次の順で表示します。

| 経過 | 演出 |
| --- | --- |
| 0ms | 英単語が小さく登場。約180msで1.16倍まで膨らみ、450msで柔らかく静止 |
| 200ms | 日本語訳が下から浮かび、クリーム色の小さなラベルに表示 |
| 350ms | 得点が小さく弾み、金色の光が一度きらめく |
| 800〜1000ms | 全体が自然に縮小・フェードアウトし、1000msで非表示 |

通常は4個の小さな星、2連鎖は6個、3連鎖は金色の星と単語周りの淡い光、4連鎖は虹色の星を添えます。大きな背景グラデーションは撤去し、英単語の白い縁取りと訳・得点の小さなラベルで読みやすくしています。装飾は固定6要素だけを使い回し、必要な時だけアニメーションするため、追加の粒子生成やタイマーはありません。

通常の正解と連鎖の最後は着地後すぐ入力可能で、リワードを見るための操作待ちは増えません。続く連鎖がある場合は、1語のリワードを1秒間表示し、完全に消してから次の候補予告→消去→落下へ進みます。表示中の次の選択・リトライは古いリワードと終了タイマーを取り消します。

訳未整備の「意味は準備中」、得点・履歴は維持。動きを減らす設定では移動・拡大・星・きらめきを止め、同じ情報を静止表示します。

`node tests/reward-browser.cjs` では着地前の非表示、英単語の拡大・行き過ぎ・静止、訳と得点の遅延、1秒の終了境界、PC/390px/320px幅で6文字が収まること、選択時の即時消去、訳未整備、動きを減らす設定を検証します。既存のeffects/animation/characterテストも、新しい表示順に合わせて時間を更新しています。連鎖のテストでは全段階で消去・落下中に中央表示が出ていないことを確認します。
