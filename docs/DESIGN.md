# パステルのゲーム画面

ユーザーのデザイン見本を参考に、画像を背景に貼る方式ではなくHTML/CSSで画面を再構成しました。

- 背景：水色・ミント・ピンク・ラベンダーのグラデーションと、淡い光の飾り。
- ブロック：7色のグラデーション、ハイライト、内側の光沢、下側の影で立体感を表現。
- 盤面：7列×8行を維持。淡い金色の立体フレーム。
- 上部：スコア、仮キャラクター、遊び方・リトライ・自動連鎖の設定。
- PCの右側：直近3つの英単語と日本語訳。最新の語を上に表示。総発見数と得点は過去の分もそのまま加算。
- 幅700px以下：盤面を優先して、直近3語を盤面下に横並びで表示。
- 日本語訳を併記するRECENT WORDS、初回チュートリアル、15秒ヒント、盤面中央の発見演出を維持。

当初はゲーム画面のロゴとタイトル・導入文を削除しましたが、その後のUI仕上げでロゴと短いリボンのキャッチコピーを追加しています（[UI-REFINEMENT.md](UI-REFINEMENT.md) の最新項目）。ブラウザのタブ名と読み上げ向けの画面名にはWord Pop!を残しています。手数制限、星ゲージ、音声ボタン、その他未実装の機能は追加していません。

## 後からキャラクターを入れる場所

`index.html` の `.character-space` が差し替え場所です。現在の `.mascot` はCSSだけの仮表示です。正式な画像を用意したら、`.mascot` 部分を透過PNG/WebPの `img` に置き換え、`.character-caption` を外します。画面全体を1枚の画像に置き換える必要はありません。

ブロックの色は `game.js` の `data-color` と、`style.css` の `.tile[data-color]` で指定しています。色分けは見た目だけで、抽選・判定・得点には影響しません。ゲームの乱数も消費しません。

## 検証

```sh
node --test tests/*.test.cjs
node tests/design-browser.cjs
node tests/browser.cjs
node tests/learning-browser.cjs
node tests/effects-browser.cjs
```

HTTPサーバーとPlaywright/Chromiumのある環境で実施。盤面56マス、タイトル削除、右側の直近3語・訳、4語目で最古を外す動作、意味の見返し、320/390px幅を確認します。既存のなぞり・落下・補充・連鎖・加点・ヒント・発見演出も実ブラウザで検証します。実機のiPhone/AndroidやSafariは未検証です。

## 周辺UIの仕上げ

文字ブロックの背景・光沢・影・字体・色分けは維持し、周囲の装飾だけを更新しました。`game.js` と `engine.js` は変更していません。

- 盤面の縁に、金色の多重シャドウ・白い反射・厚みを追加。左右上部の星は装飾で、ゲージや報酬を表すものではありません。星・反射は操作を遮りません。
- スコアは青い立体パネル。見出しはHTMLで「SCORE」、得点と発見数もHTMLのまま更新されます。
- 履歴は青い立体ウィンドウ＋クリーム色のカード。「RECENT WORDS」の見出しと、直近3語の英単語・日本語訳を表示します。以前の順位用のCSSカウンターと番号装飾は削除しました。
- 仮キャラクターは盤面に重ねて固定し、上端から顔と手を出す配置にしました。選択中文字の欄は盤面の下へ移し、顔を隠さないようにしています。
- 英語の見出し・得点・履歴の英単語にはFredokaを使います。日本語訳は既存の読みやすい日本語フォントです。文字ブロックには新フォントを適用していません。
- モバイルでもキャラクターを盤面上部に置き、履歴3語は引き続き盤面下に横並びで表示します。

### 今後、画像素材に置き換えると効果的な箇所

1. **キャラクター**：透過背景の顔・上半身・手の素材。盤面の上端をつかむポーズにすると、現在の配置にそのまま合わせられます。
2. **枠の角・星・葉などの飾り**：光の反射や細かな金属の質感は、小さな透過素材にすると描き込みやすくなります。なぞりの判定に重ならない配置を維持します。
3. **スコア・履歴ウィンドウの縁や光沢**：必要なら伸縮できる枠の素材へ置き換えられます。文字と数値を画像に焼き込まず、中央はHTMLのまま残します。

ゲーム画面全体や単語・数字を1枚の画像にしないことで、画面幅の変更・履歴更新・読み上げに対応できます。

最新の配置・操作パネル・履歴表示は [UI-REFINEMENT.md](UI-REFINEMENT.md) を参照してください。
