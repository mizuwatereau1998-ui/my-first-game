# Word Pop! 実装計画

元の仕様書は [SPEC.md](SPEC.md)。今回の成果物は仕様書の第1・第2段階を中心とする「最初に遊べる版」です。仕様書全体の完成版ではありません。

## 技術構成

- **HTML**：盤面、得点、説明など、画面に置くものを定義します。
- **CSS**：配色、丸い文字ブロック、スマートフォン向けの並び替え、消去・落下の動きを担当します。
- **JavaScript**：なぞる操作、単語の正誤、文字の落下、得点を処理します。
- **Pointer Events**：マウスとタッチを同じ処理で扱う、ブラウザの標準機能です。
- **localStorage**：ブラウザ内の小さな保存領域。現在はチュートリアル完了状態だけを保存します。後で単語コレクションにも使います。
- **音声読み上げ**：第3段階でブラウザ標準の音声機能を使います。使えない端末では案内を表示する予定です。

ゲーム用のサーバー、アカウント、外部API、フレームワーク、ビルド作業は不要です。ファイルをそのまま開いて遊べます。テストには Node.js と、実ブラウザを自動操作する Playwright を使いますが、プレイヤーには不要です。

## 作る順番と完成の目安

### 第1段階：基本ループ（実装・検証済み）

7×8盤面 → マウス・タッチ選択 → 8方向隣接判定 → 3〜6文字の登録単語照合 → 消去 → 列ごとに落下 → 補充 → 再操作。

同じマスの重複禁止、直前のマスに戻る取り消し、操作キャンセル、処理中の操作抑止を含みます。1文字10点、同じ単語も再び得点します。履歴は今回のプレイだけの記録です。

### 第2段階：初期配置と最初の1語（実装・検証済み）

- CAT・DOG・SUN・BOOK を固定の経路に置き、残りを重み付きで生成。
- 横・縦・斜めの経路を用意。固定配置同士に矛盾がないため、初期盤面の再抽選は不要。
- 最初の CAT の経路と順番を表示。プレイヤーが1語正解したら案内終了。別の登録単語で正解しても終了。
- 完了状態はブラウザに保存し、再読み込みやリトライで案内し直さない。保存できない環境でも遊べる。
- 補充は母音40%、子音60%。E/A、R/S/T/L/N等を多め、U、Q/X/Zは少なめ。母音率は抽選の確率であり、盤面内の厳密な比率ではない。
- 補充後に単語探索を行い、解がない場合は下端の3マスに CAT を置く。再抽選を繰り返さず、有限処理で進行不能を避ける。救済が起きたことを画面に表示。

### 第3段階：学習機能（一部実装）

1. 正解した単語の日本語訳と NEW 表示。
2. 発音ボタンと、音声機能非対応時の表示。
3. 現在の盤面から解を探し、意味→頭文字・文字数→経路の無料ヒント。
4. 重複しない単語コレクションと localStorage 保存。
5. 再読み込み、保存不可・データ破損時の確認。

`words.js` は意味付きデータ、`engine.js` は実在する経路を探す機能を準備済みです。現在の「見つけたことば」は保存付きコレクションではありません。

### 第4段階：画面・演出（基本の外観のみ実装）

現在は直接ゲーム画面が開きます。タイトル画面、コレクション画面、再開・タイトルへ戻るメニューを順に追加します。消去と落下の簡単な動き、遊び方、リトライ確認は実装済みです。効果音とコンボは後回しです。

### 第5段階：端末確認と公開（未完了）

PCの実ブラウザとモバイル相当の自動テストは実施。実機の iPhone・Android、Safari、音声再生、最終版の保存・メニューを確認した後、GitHub Pages 等の静的サイト公開を検討します。現在は公開URLの作成やデプロイは行っていません。

## 初版のファイル構成

```text
index.html                 画面
style.css                  見た目・アニメーション・画面幅への対応
game.js                    画面と入力、正解処理の進行
engine.js                  盤面・隣接判定・落下・探索（画面から分離）
words.js                   日本語訳付きの基本語
vocabulary.js              基本形中心の正解用3,000語
README.md                  遊び方・起動・検証方法
docs/SPEC.md               受領した仕様書
docs/PLAN.md               この計画と実装範囲
tests/engine.test.cjs      盤面ルールの自動テスト
tests/browser.cjs          実ブラウザによる操作テスト
```

処理を `engine.js` に分ける理由は、見た目を変えるときも、落下や隣接判定が壊れていないことを自動で確認できるようにするためです。

## 語彙方針の更新

正解用の語彙は基本形中心の3,000語に拡張しました。複数形・時制変化・比較変化は対象外です。入試語彙の公式リストとの照合と、日本語訳の全語整備は未完了です。出典と再生成手順は [VOCABULARY.md](VOCABULARY.md) に記載しています。

## 発見しやすさ・連鎖の更新

ユーザーの方針により、なぞりは縦横斜めの一直線だけに変更しました。初期に10種類以上の身近な語を置き、補充の候補比較と最大4連鎖の自動消去を追加しています。元の仕様書の曲がる経路と将来コンボの記述より、この追加方針を優先しています。詳細は [GAMEPLAY.md](GAMEPLAY.md) を参照してください。

## 連鎖と補充の再調整

ユーザーのプレイ感想を反映し、単語になるよう補充文字を調整する処理を撤去。通常補充は1文字ずつの重み付き抽選に戻しました。補充文字だけの単語も、既存文字と混ざる単語も、偶然そろった新規の単語なら連鎖可としています。既存文字だけの場合も、単語全体の平行移動は連鎖にしません。複数候補は中央に近いものを優先します。

## 意味表示・自動ヒントの追加

日本語訳381語の正解時表示と履歴からの見返しを追加しました。訳未整備語の正解判定は維持し、意味を準備中と表示します。15秒無操作で現在の盤面の答えが震える自動ヒントも追加。発音・ボタン式3段階ヒント・保存付きコレクションは今後の作業です。詳細は [LEARNING.md](LEARNING.md) を参照してください。

## 発見演出の追加

第4段階の演出として、消去の瞬間に英単語・日本語訳・加点を盤面中央へ大きく表示します。連鎖ごとに入れ替え、1.4秒で自動終了。次の選択で即時に隠れ、動きを減らす設定では静止表示します。詳細は [LEARNING.md](LEARNING.md) を参照してください。

## 画像見本に合わせた画面デザイン

第4段階の見た目をパステル背景と光沢ブロックへ変更しました。ゲーム画面のタイトルを削除、上部にキャラクター用スペース、右側に訳付き直近3語の枠を配置。正式なキャラクター画像は未投入で、CSSの仮表示です。手数制限や星ゲージは対象外。詳細は [DESIGN.md](DESIGN.md) を参照してください。
