# 90秒チャレンジと3ページの遊び方

従来の制限時間なしのプレイを、追加指示により90秒制へ変更しました。7×8盤面、一直線・3〜6文字の判定、辞書・訳、長語の配置/補充、スコア倍率、自動連鎖の条件・最大4連鎖、ポップンと消去/落下/リワードの演出は維持します。

## 遊び方と開始

アクセス・再読み込みのたびに、遊び方を1ページ目から自動表示します。表示済み状態は保存しません。既存のCAT完了状態のlocalStorageとは独立しています。

1. 一直線8方向・3〜6文字・決定の操作。CATのブロック例と、開閉できるキーボード/選び直しの説明。
2. 正解→消去→落下/補充、文字数×10点、2〜4連鎖の倍率、偶然の連鎖。
3. SCORE/TIME、直近3種類の履歴、連鎖スイッチ、リセット、遊び方。

次へ・戻る・ページ番号・最終ページの「あそぶ！」を用意。×はスクロールする説明領域の外にあり、どのページでも1回で閉じられます。Escapeでも閉じられます。再表示は必ず先頭へ戻ります。ネイティブのmodal dialogで背後を操作できなくし、ゲーム側の入力処理でも表示中の操作を抑止しています。

操作パネルは未選択時を空欄とし、選択文字・文字数・決定ボタンだけを残します。候補数は遊び方3ページ目へ移動。初回CATの経路と番号、15秒ヒントは維持し、盤面外の重複説明は視覚的に隠しています。不正解の案内は引き続き表示します。

## TIME

制限時間は `game.js` の `ROUND_SECONDS = 90` で管理。TIMEと遊び方内の秒数も追従します。表示は切り上げ秒数で「1:30」「0:59」。残り10秒以下は黄色と小さな明滅で案内し、動きを減らす設定では明滅しません。

最初の遊び方を閉じた時点で開始します。遊び方の再表示・タブ非表示・リセット確認中は一時停止。閉じる/戻ると残りミリ秒から再開し、遊び方とタブ非表示が重なっても両方が解除されるまで再開しません。消去・落下・連鎖・リワード表示中も時間は進みます。

残り時間は `performance.now()` による期限から求め、更新処理の遅延によるズレやタイマーの二重起動を防ぎます。開始前・時間切れ後にはカウントしません。

## 時間切れと集計

0秒で入力を止め、TIME UP!を600ms表示してからリザルトへ進みます。

- 得点は従来どおり、各単語の落下が完了した時点で確定します。時間切れの時点でまだ消去/落下中の単語は加点しません。
- すでに確定した単語のリワード表示中・次の連鎖予告中の時間切れでは、その単語までを記録します。
- 非同期処理はラウンドごとの番号で識別。各待ち時間の後と入力前に期限を確認し、終了時に待機タイマーを解除して古い処理を終了します。古いfinally処理が新しいゲームの入力や表示を変更することも防ぎます。
- 粒子・発見演出・選択経路・落下クラスとキャラクターの復帰タイマーを解除します。

RESULTでは最終得点、総発見数（重複を含む）、確定した最大連鎖を表示します。発見ゼロなら最大連鎖も0、通常の正解があれば1です。

単語一覧は直近3種類に限定せず、そのプレイで発見した全種類を最後に見つけた順に表示。各語の日本語訳と発見回数をまとめ、RECENT WORDSと同じ集計方法を使います。未整備訳は「意味は準備中」。長い一覧はウィンドウ内でスクロールし、スコアとリトライ操作を見やすく保ちます。キャラクターは既存の通常PNGを再利用します。

## やり直し

「もう一度あそぶ！」は遊び方を挟まず、全記録・残り時間・盤面・選択・最大連鎖・進行中の処理を初期化してすぐ開始します。「はじめから」も同じ初期化を行い、プレイ中は得点ゼロでも確認ダイアログを出します。キャンセルすれば残り時間から継続します。

初回CATの完了状態と自動連鎖スイッチの選択は、従来どおり維持します。ゲームを再読み込みすると遊び方が再表示され、新しいプレイになります。結果の永続保存・ランキング・音は追加していません。

## 検証

`node tests/round-browser.cjs` で、3ページの切替/全ページの×/最終ボタン/再読み込み、開始前の停止、遊び方とタブ非表示の一時停止、リセット確認、重複集計、複数回のリトライ、消去前・落下中・連鎖中の時間切れ、終了後の入力抑止と古い加算の防止、一覧スクロール、PC/390px/320px/横画面のダイアログを検証します。競合テストのみ時間定数を1〜2秒へ差し替え、その他は実際の90秒設定を仮想時計で検証します。

既存の10本のブラウザテストは、アクセス/再読み込みの後に×を実際に押してから、従来のゲーム操作と演出の検証を継続します。ルールのNodeテストも実行します。実機スマートフォン・Safariは未検証、file://はクラウドの制限でスキップされる場合があります。
