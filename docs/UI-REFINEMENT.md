# UIの配置・統一感の改善

## 今回の変更

- ポップンの表示領域をPC170→238px、スマートフォン128→180pxに拡大。透過PNGの縦横比は維持し、全身ポーズごとの顔の位置・サイズをCSSで補正。足元を切り取り、最上段の文字へかぶらないようにしています。
- PCのスコアと操作ボタンを下げ、盤面と履歴の上端をそろえました。盤面幅と文字ブロックの色・光沢・フォントは維持しています。
- 小さなフォーム状だった下部を、青い立体パネル＋選択文字＋金色の決定ボタンへ統合。「0 / 6」の文字数と一直線の説明を残しました。
- 右上の遊び方・リトライのボタンを立体化。自動連鎖はネイティブのチェックボックスを維持しながらスイッチとON/OFF文字を表示します。
- 連鎖表示を下部の操作パネルに重ねる金色のカプセルへ移動。ポップンから離し、連鎖終了時には隠します。非表示時はレイアウト上の領域を取りません。単語・訳・加点の大きな発見演出は維持しています。
- 「ことばのメモ／WORD NOTE」はHTMLから削除。日本語訳は発見演出とRECENT WORDSに残しています。

## 履歴の表示

従来のコードは直近3回を表示しており、同じ単語が重複していました。ユーザー指定の「直近3種類＋発見回数」に合わせ、既存の `found` 配列から表示を組み立て直します。

例：CAT→CAT→DOG→SUNなら、表示は SUN（1回）、DOG（1回）、CAT（2回）。合計発見数は4回、得点は従来どおり120点（連鎖なし）です。同じ単語で得点するルールや元の発見記録は変更しません。発見回数には自動連鎖の正解も含み、リトライ時にリセットします。順位番号と履歴内の連鎖倍率表記は使いません。連鎖倍率は盤面上の演出で表示します。

## 変更していないもの

`engine.js` と `character.js` は変更していません。7×8盤面、単語判定、得点計算、落下、補充、連鎖候補・上限、ヒントの待ち時間・答え、ポップンの表情切り替えと復帰タイマーは維持しています。`game.js` の修正は履歴の描画、削除したメモへの参照撤去、表示文言・連鎖ラベルの表示終了に限ります。
