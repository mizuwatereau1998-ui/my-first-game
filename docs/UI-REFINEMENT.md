# UIの配置・統一感の改善

## 今回の変更

- ポップンの表示領域をPC170→238px、スマートフォン128→180pxに拡大。透過PNGの縦横比は維持し、全身ポーズごとの顔の位置・サイズをCSSで補正。足元を切り取り、最上段の文字へかぶらないようにしています。
- PCのスコアと操作ボタンを下げ、盤面と履歴の上端をそろえました。盤面幅と文字ブロックの色・光沢・フォントは維持しています。
- 小さなフォーム状だった下部を、青い立体パネル＋選択文字＋金色の決定ボタンへ統合。「0 / 6」の文字数と一直線の説明を残しました。
- 右上の遊び方・リトライのボタンを立体化。自動連鎖はネイティブのチェックボックスを維持しながらスイッチとON/OFF文字を表示します。
- 連鎖表示を下部の操作パネルに重ねる金色のカプセルへ移動。ポップンから離し、連鎖終了時には隠します。非表示時はレイアウト上の領域を取りません。単語・訳・加点の大きな発見演出は維持しています。
- 「ことばのメモ／WORD NOTE」はHTMLから削除。日本語訳は発見演出とRECENT WORDSに残しています。

## 履歴の表示

従来のコードは直近3回を表示しており、同じ単語が重複していました。ユーザー指定の「直近3種類＋発見回数」に合わせ、既存の `found` 配列から表示を組み立て直します。

例：CAT→CAT→DOG→SUNなら、表示は SUN（1回）、DOG（1回）、CAT（2回）。合計発見数は4回、得点は従来どおり120点（連鎖なし）です。同じ単語で得点するルールや元の発見記録は変更しません。発見回数には自動連鎖の正解も含み、リトライ時にリセットします。順位番号と履歴内の連鎖倍率表記は使いません。連鎖倍率は盤面上の演出で表示します。

## 変更していないもの

`engine.js` と `character.js` は変更していません。7×8盤面、単語判定、得点計算、落下、補充、連鎖候補・上限、ヒントの待ち時間・答え、ポップンの表情切り替えと復帰タイマーは維持しています。`game.js` の修正は履歴の描画、削除したメモへの参照撤去、表示文言・連鎖ラベルの表示終了に限ります。

## ヘッダーとRECENT WORDSの仕上げ（最新）

上記の初回整理に続き、プレイ画面にWord Pop!のロゴを追加しました。既存のFredokaでピンク・水色・黄色の立体文字とし、下に青い小さなリボンで「なぞって単語をつくろう！」を表示します。タイトル画面・開始ボタン・追加画像・アニメーションは追加していません。

ロゴはヘッダー上段、SCOREと操作ボタンは下段です。ポップンは従来どおり盤面に固定し、サイズ・顔の位置補正・動きは変更していません。中間のPC幅ではSCOREをコンパクトにしてキャラクターと重ならないようにしています。スマートフォンの操作ボタン・連鎖スイッチは高さ44px以上を保ちます。

常設の「タテ・ヨコ・斜めにまっすぐ」は外し、「遊び方」の一直線ルール・操作説明へまとめました。選択欄の未入力表示は「選択した文字」に変更し、入力欄・文字数・決定ボタンを優先。「5〜6文字の単語 ○ 個」は操作パネル内の小さな情報へ移動しています。初回CATのチュートリアルとヒント表示は維持。通常の重複するフィードバックは読み上げに残し、不正解時の案内は画面にも表示します。

RECENT WORDSの補足文は削除。水色の外枠とクリーム色のカードは維持し、左端に4pxの水色ラインを付けました。英単語の下に日本語訳、右側に「1回」「2回」の小さな表示を配置します。読み上げでは従来どおり「発見○回」と伝えます。メダル・順位・得点は追加していません。直近3種類・重複集計・表示順・リトライ時のリセットは同じです。

PCは盤面と履歴を横並び。スマートフォンでは盤面の下に履歴を置き、従来のカード3列を縦3枚に変更して、6文字の英単語と日本語訳を読みやすくしました。未発見時は3枚の空き枠で表現し、長い説明文は画面に出しません。

ゲームのルール・辞書・得点・ヒント処理・画像・消去/落下/連鎖/発見演出の処理とCSSは変更していません。`game.js` の今回の変更は、回数の表示文と選択欄の未入力表示の2か所だけです。

追加検証は `node tests/ui-polish-browser.cjs`。実際にCAT・6文字・5文字を消し、1200/1000/900/768/701/700/390/320px幅でロゴ・キャラクター・各操作の非重複、横はみ出し、カードの回数位置、ボタンの大きさ、遊び方・自動連鎖・リトライを確認します。既存の重複単語・集計のテストは表示を「○回」に更新して継続しています。

PC・390px・320px幅のスクリーンショットは `/workspace/scratch/word-pop/ui-polish-1200.png`、`ui-polish-390.png`、`ui-polish-320.png` へ出力します。実機スマートフォン・Safariの検証は未実施です。
