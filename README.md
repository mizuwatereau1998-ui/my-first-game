# Word Pop!

隣り合うアルファベットをなぞって英単語を作る、小さなブラウザゲームです。1プレイ90秒で、見つけた単語と得点をリザルトで振り返れます。アカウント登録は不要です。

現在は、仕様書の第1・第2段階を中心とした最小プレイ版です。詳しい実装計画は [docs/PLAN.md](docs/PLAN.md)、受領した仕様書は [docs/SPEC.md](docs/SPEC.md) を参照してください。

## 遊ぶ方法

いちばん簡単なのは、フォルダ内の **`index.html` をブラウザで開く** 方法です。インストールやビルドは不要で、外部フォント・画像・APIにも依存しません。

開発用にHTTPで開く場合は、Python 3 のある環境で次を実行します。

```sh
cd /workspace/my-first-game
python3 -m http.server 8000 --bind 0.0.0.0
```

同じコンピューターのブラウザで `http://localhost:8000` を開きます。アクセス・再読み込みのたびに3ページの遊び方が表示され、×または最終ページの「あそぶ！」で閉じると90秒のプレイが始まります。終了はターミナルで Ctrl+C。これはローカルの開発サーバーであり、一般公開されたURLではありません。クラウド環境から手元のブラウザで見るには、その環境が用意するポート転送等が必要です。スマートフォンで開く場合も、到達可能なHTTP配信先が必要です。

## 操作

1. 初回は光っている **C → A → T** をマウスで押したまま、または指でなぞります。
2. 指・マウスを離すと判定します。正解なら消えて、上の文字が落ち、新しい文字が補充されます。
3. 次からは **3〜6文字** の英単語を、縦・横・斜めの一直線で探します。逆方向も使えますが、L字やジグザグには曲がれません。
4. 同じマスは1回だけ。直前のマスに戻ると1文字取り消せます。
5. 右上の「?」で遊び方、「はじめから」で今回の得点と履歴をリセットできます。

キーボードは Tab で盤面に移り、矢印キーで移動、スペースで文字を選択、Enterで決定、Escで選択取り消しです。

チュートリアルは1語正解すると終了し、完了状態をブラウザに保存します。初回案内を再確認するには、開発者ツールのコンソールで `localStorage.removeItem('word-pop-tutorial-complete-v1')` を実行して再読み込みしてください。ストレージを禁止しているブラウザでは保存されませんが、ゲームは続けられます。ファイルを直接開く場合の保存動作はブラウザにより異なるため、保存の確認にはHTTP配信をおすすめします。

## 単語を追加する

`words.js` の `WordPopDictionary` に、次のような項目を追加します。

```js
CAT: '猫',
DOG: '犬',
```

キーは3〜6文字の大文字にしてください。現在は基本形を中心とする3,000語の固定単語帳を使い、未登録の単語・複数形・過去形などは正解にしません。追加語彙と出典・利用条件は [docs/VOCABULARY.md](docs/VOCABULARY.md) を参照してください。日本語訳は次段階の学習機能に利用する準備データで、ゲーム画面での表示は未実装です。

## 動作確認

Node.js の標準テスト機能で、追加パッケージなしに盤面ルールを確認できます。

```sh
node --test tests/*.test.cjs
```

実ブラウザ検証は、HTTPサーバーを起動した状態で、Playwright と Chromium が利用できる開発環境で実行します。このクラウド環境には両方が用意されています。

```sh
node tests/browser.cjs
```

別環境では Playwright を別途準備し、必要に応じて `CHROMIUM_PATH` と `GAME_URL` を指定します。ブラウザテスト用のパッケージはゲーム本体には必要ありません。スクリーンショットは `/workspace/scratch/word-pop/` に出力します。

検証対象：8方向の隣接、重複禁止、取り消し、文字数制限、登録単語照合、落下順序、補充、母音率、解なし盤面の救済、マウス、タッチ、縦・横・斜めの単語選択、キーボード、チュートリアル保存、リトライ、タッチキャンセル、320px幅での横はみ出し。

## 発見しやすさ・自動連鎖の更新

初期盤面には身近な単語を10種類以上置き、補充は母音・子音の出現率を調整した1文字ずつのランダム抽選です。補充時に単語を埋め込む処理は撤去しました。「見つけやすい単語 ○ 個」が次に探せる身近な語の種類数です。

**自動連鎖は標準でON**。落下・ランダム補充後に偶然新しくそろった身近な3〜4文字の一直線単語を自動で消し、2連鎖は2倍、3連鎖は3倍、最大4連鎖まで加点します。そろった文字を強調し、単語と加点を表示します。落下・連鎖中は操作を待ってください。補充された文字だけでも、偶然そろえば連鎖します。手動でゆっくり遊びたい場合は「自動連鎖」のチェックを外します。

詳しいルール・補充の仕組み・検証は [docs/GAMEPLAY.md](docs/GAMEPLAY.md) に記載しています。

## 語彙更新

3〜6文字の基本形を中心に3,000語へ拡張しました。ゲーム配布時は `vocabulary.js` も `index.html` と同じフォルダに置いてください。追加語彙の出典・ライセンス通知として `docs/VOCABULARY.md` と `licenses/` も同梱してください。

## 単語の意味・自動ヒント

正解すると盤面の発見演出とRECENT WORDSに日本語の意味を表示します。現在は381語分で、訳未整備の登録語は「準備中」と表示します。履歴の単語を押すと意味を見返せます。

操作せず15秒待つと、今の盤面にある答えのブロックが番号順に軽く震えます。操作を再開すると止まり、選択中・消去落下中・遊び方の表示中には出ません。動きを減らす設定では色と番号で案内します。

説明とテスト方法は [docs/LEARNING.md](docs/LEARNING.md) を参照してください。追加の自動確認は `node tests/learning-browser.cjs` で実行できます。

## 発見した単語の演出

消去・落下・着地の後、盤面中央へ英単語が大きく弾んで表示され、0.2秒後に日本語訳、0.35秒後に得点が登場します。全体は約1秒で消え、次の連鎖の消去・落下には重なりません。次の文字を選べば演出はすぐに消え、操作を遮りません。意味はRECENT WORDSでも見返せます。動きを減らす設定では静止表示になります。検証用コマンドは `node tests/effects-browser.cjs` です。

## 5〜6文字を主役にした配置

配置用の語彙を訳付きの5〜6文字157語に絞り、初期盤面には5文字3語・6文字3語を置きます。長い単語が減ると、新しく補充するマスだけを使って5〜6文字の候補を作ります。従来の短語を増やす補充とは異なり、配置した長い語が部分的な3文字の連鎖で即消去されないよう保護します。15秒ヒントも長い語を優先します。

正解用3,000語と得点計算は維持しています。初回CATの後は、少し長めに盤面を見渡すか15秒待って、5〜6文字の単語を探してみてください。最新の配置ルールは [docs/LONG-WORDS.md](docs/LONG-WORDS.md) を参照してください。以前の「常にランダム補充」の記述より、この長語優先のルールを適用します。

## キャラクター「ポップン」

`assets/characters/` の4枚を使い、通常・正解・2連鎖・3連鎖以上で表情を切り替えます。待機中はゆっくり上下、正解時は小さくジャンプ。連鎖が終わってから通常へ戻ります。画像が読めなくても仮キャラクターで遊べ、動きを減らす設定にも対応しています。詳細は [docs/CHARACTER.md](docs/CHARACTER.md)、表示テストは `node tests/character-browser.cjs` です。

## UIの配置整理

ポップンを約1.4倍に拡大し、正解・連鎖の全身ポーズも顔の位置を補正します。選択文字と決定ボタンを青いゲーム用パネルにまとめ、自動連鎖はスイッチとON/OFF表示で確認できます。重複する「ことばのメモ」は削除し、RECENT WORDSを直近3種類・日本語訳・各単語の発見回数の表示にしました。得点計算などのルールは変更していません。詳細は [docs/UI-REFINEMENT.md](docs/UI-REFINEMENT.md) を参照してください。


## アニメーションの仕上げ

選択したブロックはぷくっと反応し、正解時は順番に弾けて星と光が散ります。落下は画面幅に合った実際のマス間隔で移動し、元のブロックの色を保って柔らかく着地します。2〜4連鎖では段階的に光が増え、ポップンは弾け始めに喜びます。ルール・抽選・辞書・画像・画面構成は維持しています。

配布時は追加の `motion.js` も他のJavaScriptと同じフォルダに入れてください。詳しいタイミングと検証は [docs/ANIMATION.md](docs/ANIMATION.md)、追加のブラウザ検証は `node tests/animation-browser.cjs` です。

## 90秒チャレンジ・遊び方・リザルト

遊び方は毎回自動表示され、どのページからも×で閉じられます。プレイ中の「遊び方」やタブ非表示中はTIMEが一時停止。時間切れ後は最終得点・総発見数・最大連鎖・今回の全単語を表示し、「もう一度あそぶ！」ですぐリトライできます。「はじめから」は確認後に90秒からやり直します。

操作パネルの未選択時は空欄で、文字数と決定ボタンだけを残しました。従来のCAT経路・15秒ヒント・直近3種類の履歴・消去/落下/連鎖/リワード演出は維持しています。時間設定と時間切れの扱い、検証は [docs/ROUNDS.md](docs/ROUNDS.md) を参照してください。以前の「制限時間なし」という記述より、この90秒制を適用します。
